# Outputs

Folder ini menyimpan hasil evaluasi pelatihan.

- `results/model_comparison.csv` — tabel perbandingan 3 model.
- `results/confusion_matrix.png` — confusion matrix model terbaik.
- `results/roc_curve.png` — kurva ROC semua model.
- `results/training_summary.json` — ringkasan metrik & informasi dataset.

Semua angka berasal dari hasil prediksi model yang sebenarnya.
